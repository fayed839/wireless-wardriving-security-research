# Sanitized Sample Data

This folder is reserved for privacy-safe sample data used to demonstrate analysis workflows.

Recommended approach:
- Use synthetic or heavily sanitized examples when possible.
- Replace real SSIDs with neutral labels such as `network-001`.
- Remove or hash BSSIDs/MAC addresses.
- Generalize coordinates or remove them entirely.
- Keep only fields necessary for aggregate security analysis.

Do not publish credentials, private traffic, exact home locations, or unnecessary identifying information.
