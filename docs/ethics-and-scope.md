# Ethics and Scope

## Authorized Use Only
This project is intended for lawful wireless-security education, defensive research, and observation of environments where the activity is permitted.

## Out of Scope
This repository does not cover:
- Unauthorized network access
- Password or credential attacks
- Deauthentication or disruption
- Capturing private user communications
- Tracking individuals
- Publishing identifying network information without a legitimate reason

## Privacy Principles
- Minimize collected data.
- Prefer aggregate statistics.
- Sanitize identifiers before publishing.
- Avoid precise location data tied to identifiable networks.
- Review screenshots manually before committing them.

## Reporting Standard
Any claims in this repository should be supported by real observations. Do not fabricate network counts, security percentages, geographic results, or screenshots.
